## ❓ FAQ

**Do I need to run it as Administrator?**
Yes — admin rights are required for the overlay to attach.

**Does it work with antivirus software?**
Security tools may flag custom firmware files. Add exclusions for your memory stick directory.

**Is it compatible with Windows 11?**
Yes, file management and preparation work on Windows 10 and 11.

**Does ARK-5 work on PS Vita?**
Yes, through the ePSP environment. Overclocking is limited on Vita hardware [citation:5].

**How do I update ARK-5?**
Replace the files on your memory stick with the latest release and run the installer again.
